# U2 Lab

Тестовая лаборатория U2 в браузере. Здесь подбирают и проверяют параметры ТТХ кораблей,
моделируют энергию, тепло и излучение (IR/EM) и сравнивают сборки на воспроизводимых опытах.

U2 остаётся источником утверждённых правил и ТТХ. Лаба хранит эксперименты, версионные
наборы параметров и результаты; числа с пометкой experimental/candidate не становятся
каноническими ТТХ U2.

## Открыть

[komleff.github.io/u2-lab](https://komleff.github.io/u2-lab/) — установка не нужна,
расчёт идёт в браузере через Worker.

| Адрес | Что откроется |
|---|---|
| `/` | GD LAB v2.4 · UI 4.8: оснастка, условия рейса, графики, сравнение A/B, сигнатуры |
| `/?shipModel=experimental` | Модель корабля `/4`: каталог 0.3.2 (14 конфигураций S/M), тепловой каскад, износ, IR/EM и дальности обнаружения |
| `/?mode=legacy` | Обновлённый Legacy Power & Heat 0.1.1 |
| `/legacy-v1/` | Самая первая Power & Heat Lab |

## Что умеет

- **Оснастка.** Корабли S/M, слоты и модули, каталог с поиском, JSON-импорт и экспорт.
- **Рейс.** Порожний и загруженный полёт, добыча до заполнения трюма, разгрузка,
  заправка и зарядка на станции, повторные рейсы.
- **Энергия и тепло.** Генераторы, аккумуляторы, радиаторы, тепловой буфер,
  термоинвертор как тепловой насос, H₂-охлаждение, температурные зоны космоса.
- **Сигнатуры.** IR и EM по источникам, история за весь опыт, дальности обнаружения
  сенсорами S/M.
- **Модель корабля `/4`.** Фазы и режимы, каскад охлаждения с шагом 1 с, износ и отказы,
  маскировка, сохранение и продолжение опыта.
- **Анализ.** Графики, журнал, общий курсор времени, зафиксированный вариант A против
  черновика B, экспорт JSON/CSV.

## Запуск локально

```bash
git clone https://github.com/komleff/u2-lab.git
cd u2-lab
npm ci
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

Откройте `http://localhost:4173` или `http://<LAN-IP>:4173` с другого устройства в сети.
Готовую `dist` можно раздать и так:
`python3 -m http.server 4173 --bind 0.0.0.0 --directory dist`.

Проверки: `npm test`, `npm run test:browser`, `npm run typecheck`; полный набор —
`.agents/project/verify.sh`.

## Как ведётся работа

Pipeline — OverGate v4 (`.agents/`), задачи — Beads (`bd`), контекст — `.memory-bank/`.
Работа идёт в рабочих ветках через PR от `main`; merge выполняет оператор.
