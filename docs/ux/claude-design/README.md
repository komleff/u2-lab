# Claude Design: передача PM

Папка с результатами работы UX-ведущего (Claude, роль GD/UX) по двум ТЗ:
`../ship-fitting-v0.2-claude-design-brief.md` и ТЗ Power & Heat Lab (beads `ulab-5xz`).

## Что внутри

| Путь | Что это |
|---|---|
| `ship-fitting-power-heat-ux-v2.1.md` | **Главный документ.** Обоснование UX/UI решений, отклонения от ТЗ, карта функционала, 17 сценариев пользователя, правила состояний, визуальная система, указания ИИ-кодеру, открытые вопросы |
| `mockups/*.dc.html` | Исходники макетов в формате холста Claude Design (снимок версии 22 холста от 2026-10-06). `Main.dc.html` — главный экран Ship Fitting v2.1 |
| `mockups/canvas.json` | Раскладка холста: страницы, артборды, заметки |
| `mockups/ds/u2/tokens.json` | Снимок токенов дизайн-системы U2, с которыми собраны макеты |

## Как смотреть

Живой холст: `https://claude.ai/artifact/9xSDq5D5Bbz6VekPoMDvGZ` (приватный, доступ
выдаёт оператор). Файлы `.dc.html` самостоятельно в браузере не открываются: им нужен
исполнитель холста Claude Design, а картинка корабля лежит в хранилище холста.
Это образцы раскладки, а не код приложения (документ, раздел 11).
