к этому снимку. Коэффициент износа генераторов не переносится на двигатели.
Экономика и система ремонта в Лабу не добавляются.

Документальная задача: `ulab-9aa.28`, parent `ulab-9aa`.
Исходный create intent `8dc74373-24d1-44fe-8c2c-9289f1995632` сопоставлен с ней
через `external_ref=intent:8dc74373-24d1-44fe-8c2c-9289f1995632`.
Поэтому повторный create не нужен. JSONL-очередь не редактировалась;
applier/sync/export агент не запускал. Её pending-запись — исторический вход,
актуальный статус задачи читается через разрешённую Beads-обёртку.

`qualificationStatus=NOT_RUN` и `runtimeAuthorization=false` сохраняются.
Этот PR не активирует профили governor, не подменяет U2.Shared field map,
не заявляет runtime/server/Unity parity и не снимает блокер серверной схемы
перезапуска. Проверка документов отделена от физических опытов и приёмки runtime.
