# Исходная продуктовая база F2

Снимок ниже заморожен на 24.10.2026: каталог 0.3.2 и прежние опыты сохранены
побайтно. Его значения не заменяют принятые позднее физические данные 0.3.4.
[Актуальные владельцы данных и регистрация Beads](CURRENT-STATUS.md).

Решение оператора: корпус — самостоятельный модуль и агрегатор установленного
оборудования. Каждое изделие имеет собственные ТТХ. Сборка содержит ссылки на
паспорта изделий и количество экземпляров; оборудование не становится частью
массы голой оболочки. Встроенные изделия также перечисляются отдельно.

Пакет использует существующие таблицы U2, каталог Лабы 0.3.2 и устроившие оператора
прежние прогоны 0.2.5. Новые целевые времена штатной работы вместо этих опытов
не назначены. Поля canonical/candidate и конкретные отсутствующие параметры
различены; исходная маркировка старых JSON сохранена как происхождение значения.

## Состав

В каталоге [product-baseline-v0.1](product-baseline-v0.1/):

- [Читаемый отчёт](product-baseline-v0.1/report.html) — корпуса, ведомости оснащения,
  собственные ТТХ изделий, происхождение чисел и адресные предложения.
- [hulls](product-baseline-v0.1/hulls/) — три корпуса: Спутник, Severin Mir, Diesel Pony.
- [modules](product-baseline-v0.1/modules/) — 48 отдельных паспортов установленных,
  встроенных и локальных изделий, а также средств охлаждения для сравнения вариантов.
- [assemblies](product-baseline-v0.1/assemblies/) — Спутник D, Мир D/H/E и Пони D;
  поэкземплярный состав, начальные запасы, отдельные масса оболочки, оборудования
  и ресурсов, итоговая теплоёмкость.
- [sources.json](product-baseline-v0.1/sources.json) — источники и их blob hashes.
- [historical-zones.json](product-baseline-v0.1/historical-zones.json) — сохранённые
  старые температурные опыты, без объявления их результатами нового governor.
- [findings.json](product-baseline-v0.1/findings.json) — реальные расхождения и предложения.
- [scenario-contract.json](product-baseline-v0.1/scenario-contract.json) — сценарии
  работы, восстановления и отказов без алгоритмических веток под имя корабля.
- [document-verification.json](product-baseline-v0.1/document-verification.json) —
  результат проверки извлечения данных и сумм; не runtime QA.

## Идентичность и границы

| Лабораторный корпус | Игровая идентичность U2 |
|---|---|
| `sputnik` | существующий `configs/ships/strizh.json`; F1 не меняет Спутник |
| `severin-mir` | `severin_mir`, fixed preset `f1_mir_fixed` rev 1 |
| `pony` | `diesel_pony`, fixed preset `f1_pony_fixed` rev 1 |

Это соответствие имён не делает рабочие сборки Лабы фиксированными комплектами
F1. Например, оболочка Мира 170 т одинакова в исходных опорах, но его F1-транспорт
и рабочая сборка с двумя лазерами имеют разное оборудование и суммарную массу.

`sourceRevision` — хеш исходной записи, а не придуманная заводская редакция SKU.
Исторический снимок PR #39 в manifest относится к подготовке пакета, не является
текущим статусом PR. При подготовке коммита #39 открыт и не слит; его файлы не меняются.

Пакет — подготовка продуктовых данных P0. Он не подменяет предусмотренные планом
формальные qualification skeletons, U2.Shared field map и их runtime-тесты.
Поэтому данные размещены в отдельном `product-baseline-v0.1`, чтобы загрузчик
не принял их за профиль governor 0.3. `qualificationStatus=NOT_RUN`,
`runtimeAuthorization=false`. G3–G5 в эту документальную поставку не входят.

`q(T)` используется только для холодного H₂-охладителя/T22. Генератор и движитель
имеют собственные КПД, расход и потери. Водяной термобак остаётся в теплосети;
водяные движители и локальный пар вне этой поставки.

Beads остаётся единственным tracker. На момент исходного cloud-снимка отдельная
задача P0 не была найдена. Теперь документальный пакет зарегистрирован как
`ulab-9aa.28` с marker исходного create intent; очередь сохранена без изменений.
Регистрация не означает выполнения runtime qualification P0.

## Проверка

Проверены JSON, ссылки на экземпляры, совпадение чисел с исходными записями,
отсутствие двойного учёта оборудования и арифметика пяти сборок. Для четырёх
сборок теплоёмкость совпадает с прежними сохранёнными опытами. Отдельного старого
результата Мира H в этой серии нет. Работа нового governor на этих профилях
не выполнялась; PASS проверки документов не является балансной приёмкой.

## Глоссарий

- **Изделие / модуль** — отдельный узел с собственными ТТХ.
- **Сборка** — корпус и конкретные экземпляры установленного оборудования.
- **Provenance** — источник числа и способ его получения.
- **Qualification** — отдельная проверка физического поведения на принятом ядре.
