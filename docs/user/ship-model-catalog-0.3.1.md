# Каталог кораблей 0.3.1 в модели `/4`

Откройте экспериментальную модель корабля в Лабе. Новый рабочий вариант A уже
содержит **Северин Спутник · D (дизель)**; фон нового опыта — **250 K**. Вариант B
изначально пуст. Выбор корабля меняет выбранный следующий черновик, а не сохранённое
измерение или зафиксированный A.

## Четырнадцать конфигураций

В меню показаны именно эти сборки и в этом порядке. Буква обозначает установленный
силовой тракт: D — дизель, H — водород, E — электрический. Это не просто переименование
одного состава: различаются двигатели, питание и запасы ресурсов.

| ID | Подпись в меню |
|---|---|
| `sputnik-d` | Северин Спутник · D (дизель) |
| `sputnik-e` | Северин Спутник · E (электро) |
| `pony-d` | Дизельный Пони · D (дизель) |
| `ermak-d` | Демирмаш Ермак · D (дизель) |
| `ermak-h` | Демирмаш Ермак · H (водород) |
| `ermak-e` | Демирмаш Ермак · E (электро) |
| `volna-m-h` | Северин Волна M · H (водород) |
| `titan-d` | Демирмаш Титан · D (дизель) |
| `titan-h` | Демирмаш Титан · H (водород) |
| `titan-e` | Демирмаш Титан · E (электро) |
| `severin-mir-d` | Северин Мир · D (дизель) |
| `severin-mir-h` | Северин Мир · H (водород) |
| `severin-mir-e` | Северин Мир · E (электро) |
| `stealth-reference` | Стелс-сборка |

Оба Спутника содержат гражданский лазер S и насыпной трюм S. Дизельный Пони сохраняет
свои локальные варианты и встроенный лазер; Волна M H — встроенный криобак. Ермак и
Титан имеют промышленные лазеры. Встроенные системы корпуса показываются отдельно
от сменного силового тракта. Их наличие, например электрического обогревателя,
не превращает дизельную сборку в E.

## Первый опыт и сохранение

Выберите конфигурацию, проверьте состав в «Корабль» и условия в «Условия», затем
нажмите «Запустить». Фазы задают реальные запросы установленным экземплярам;
только наличие двигателя ещё не означает, что рабочая фаза запрашивает тягу.
Пауза, продолжение, шаг и отмена управляют захваченным Worker-опытом. Во время
активного опыта нельзя менять его сборку или условия; переключение вариантов
не переносит измерение другому владельцу.

В измеренном «Обзоре» первым показана «Расчётная дальность обнаружения»: IR и EM
в метрах или километрах для сохранённого наблюдателя, ракурса и профиля приёмника.
«В конце опыта», «По среднему сигналу за интервал» и «Максимальная за интервал»
имеют разные смыслы. Дальность по среднему сигналу — не средняя дальность по времени.
Это reference в чистом космосе, не фактический контакт с противником и не игровая
authority. Ватты и подробности остаются в техническом раскрытии и графиках.

Можно сохранить JSON сборки, опыта и результата. Сборка хранит монтаж и версию
каталога; опыт — полный численный snapshot условий; результат — измерения и
checkpoint. Повторное открытие сохраняет их буквально. CSV содержит сохранённые
агрегаты, а не полный архив каждого физического подшага.

Для сравнения зафиксируйте завершённый или приостановленный результат A. После
изменения его исходного черновика baseline A остаётся прежним и получает отметку
устаревания. B — только собственное измерение выбранного варианта; пустой B не
подменяется результатом активного A. Отличия условий видны до подробных паспортов.

## Версии и границы

250 K применяется только при создании нового опыта `/4`. Явный фон 100 K, среды
отдельных фаз, сохранённые начальные запасы и продолжение checkpoint не заменяются
новыми значениями. Модели `/1`, `/2`, `/3` сохраняют прежние defaults.

Сборки, опыты и результаты `ship-fitting-0.3.0` открываются и переэкспортируются
без автоматического обновления монтажа, условий или версии. Для такого выбранного
варианта доступен его старый список Спутник/Мир/Стелс; новые ID 0.3.1 не являются
алиасами старых. Неизвестная версия или несовместимый ID отклоняются без замены
текущего владельца.

Это экспериментальный каталог: дополнительные поля V3 и производные параметры
имеют происхождение в паспортах и не объявляются каноническими ТТХ. Размер L в эту
поставку не входит. Будущее имя «Северин Караван» зарезервировано, но такого пункта
в меню нет.

Developer-проверки используют локальный браузер и production Worker. Независимые
QA и Code Review — отдельные gates; server parity, native-приложение, физическая LAN
и человеческий playtest здесь не заявлены выполненными.
