# Локальный запуск

Рабочая ветка — `feat/gd-workspace-v4`. Для сборки нужны Node >=22.12 и npm:

```bash
npm ci
npm run build
python3 -m http.server 4188 --bind 0.0.0.0 --directory dist
```

Откройте `http://localhost:4188/` на хосте или `http://<LAN-IP>:4188/` на устройстве
той же сети. Последняя команда запускает и распакованный standalone. Шрифты и
изображения входят в сборку. Текущий отдельный стенд оператора —
`http://192.168.68.65:4188/`. Футер показывает **интерфейс v4.0**; численная модель
имеет свою прежнюю версию.

Сохранённые версии доступны на `http://192.168.68.65:4183/` и
`http://192.168.68.65:4186/`. Legacy Power & Heat открывается через `?mode=legacy`;
его прежняя численная модель остаётся отдельной.

# Собрать и подготовить опыт

Оснастка, условия, графики и сравнение находятся на одной прокручиваемой странице.
Якоря сверху и управление снизу доступны при расчёте. Строка контекста различает
выбранный корпус, следующий черновик, владельца активного опыта и измеренную ревизию.
Круговая схема слотов раскрывается дополнительно; основной монтаж — группы изделий.

Выбор целого пресета заменяет монтаж выбранного черновика. Для отдельной замены
выберите сменный слот, изучите каталог и предпросмотр, затем примените или отмените
выбор. Встроенные изделия не заменяются. Пакетная замена затрагивает только сменную
полезную нагрузку. Варианты A/B/C и добавленные варианты независимы.

Форма условий всегда относится к следующему черновику выбранного варианта. Она
содержит горизонт, физический шаг, исходную температуру, длительности заданных фаз,
повтор и существующие условия добычи. Рабочая фаза — заданная длительность цикла,
а не время до полного трюма. Длительности не доказывают маршрут или ETA.

В «Подробнее» можно создать локальную численную гипотезу для выбранного сменного
изделия: мощность или другое уже поддерживаемое численное поле, например efficiency.
Валидация и единицы берутся у существующей модели; происхождение обозначено
experimental. Каталог и встроенные ТТХ остаются прежними. Недопустимое значение
сохраняет последний допустимый черновик.

# Запустить, прочитать и сравнить

На странице работает один Worker. Пауза, шаг, продолжение, отмена и сброс управляют
его активным опытом. Изменение оснастки или условий готовит следующий черновик;
immutable snapshot активного опыта сохраняет прежние параметры. Второй запуск
недоступен до отмены или завершения первого. После повторного Start предыдущий
результат остаётся в варианте, а новый опыт ожидает собственные измерения.

Обзорные графики отдельно показывают запрос/выдачу, температуру с порогами, запасы
и добычу. «Полные каналы» раскрывает группы, единицы, скрытие кривых и таблицу.
Цвет и пунктир закреплены за ID канала. Ползунок времени или кнопка времени события
выбирает bucket: графики, измерения модулей и выделение журнала используют его границы.
Mean/min/max/count — агрегаты интервала. Общие результаты и конечные запасы подписаны
отдельно. Во время расчёта видимо окно последних 250 buckets и 100 событий;
retained/dropped counters показывают действительные границы, а не полную историю ticks.

Эталон A — отдельный неизменяемый снимок опыта, а не имя варианта A. Его можно
зафиксировать после завершения либо на паузе; на паузе запрашивается точный snapshot.
Затем отмените или завершите активный опыт, выберите другой вариант и запустите B.
Отмена и правки следующей сборки не меняют эталон. Compare показывает измеренные
корпус, лазеры, ёмкости, ревизию, интервал и конкретные отличия условий. Сортировка
не меняет выбранную базу сравнения. Старый результат после правки помечается устаревшим.

# Сохранить и снова открыть

«Сохранить сборку» в шапке и в «Подробнее» предлагает имя JSON-файла; его можно
изменить перед обычным скачиванием браузера. Отмена не скачивает файл и не меняет
сборку. Выбранный монтаж сохраняется без изменения формата. Экспорт опыта во время расчёта
сохраняет active snapshot; без активного расчёта — следующий опыт выбранного варианта.
Экспорт результата JSON/измерений CSV сохраняет подписанный результат выбранного
варианта, включая предыдущий после повторного Start. CSV содержит retained
mean/min/max/count, а не все физические ticks.

Импорт различает сборку, численный опыт для повторения и измеренный результат.
Опыт показывает собственный snapshot и исходные условия; правка черновика завершает
режим точного повторения и готовит обычный поддерживаемый цикл. Native result текущей
модели и каталога открывает проверенные state/metrics/trace/events для анализа без
нового расчёта. Неизвестный каталог результата или некорректные числа/каналы/интервалы
отклоняются до изменения работы. Для numerical snapshot неизвестного каталога
сохраняется отдельное явное разрешение воспроизведения без проверки слотов.

Варианты, черновики и эталон живут в памяти страницы; reload их не сохраняет.
JSON отдельного объекта не является архивом всей рабочей страницы. Реальная шахтёрская
миссия, добыча до полного трюма и заправка остаются отложенными.

На верхней границе рабочего листа отключён браузерный pull-to-refresh. Обычная
вертикальная прокрутка сохранена; ручное обновление страницы по-прежнему теряет
несохранённые варианты. Физический жест на Xiaomi этим Developer не проверен.
