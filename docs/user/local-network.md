# Запуск Power & Heat Lab0.1.1

Требуются Node24 (или совместимая версия >=22.12) и npm. Все runtime assets локальны;
каждый браузер запускает независимый Web Worker. Simulation backend, аккаунт и CDN не нужны.


Patch0.1.1 исправляет запуск по обычному LAN HTTP. В footer должно быть `Power & Heat v0.1.1`.
Run ID использует `crypto.getRandomValues`; secure-context-only `randomUUID` больше не нужен.
При обновлении остановите собственный старый сервер Ctrl+C, пересоберите dist либо распакуйте
новую standalone в отдельную папку, затем снова запустите сервер этой папки.
Для существующего адреса: `http://192.168.68.65:4173/?v=0.1.1`; если хост изменился,
используйте его реальный LAN IP. Если footer старый, проверьте server directory и обновление страницы.
HTTPS и изменение Chrome security flags для запуска не требуются.

Короткая проверка на втором устройстве: S14s/Запуск→Завершён,Сброс→0s,M14s/Запуск→Завершён,
Шаг после сброса→время>0. Для pause/resume используйте600s и ускорение×1;12h ждать не нужно.
[Подробный отчёт для локального агента на Mac](../handoffs/2026-10-05-mac-lan-http.md).
Hosted QA воспроизвела настоящую API-доступность secure=false origin собственными assets;
физический Xiaomi/второй LAN клиент проверяет оператор. Это разные поверхности проверки.

Сейчас runtime находится в draft-ветке; `main` сохраняет начальный seed до operator merge.

```bash
git clone --branch feat/power-heat-lab https://github.com/komleff/u2-lab.git
cd u2-lab
npm ci
npm run typecheck
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 4173
```

Откройте `http://localhost:4173` на хосте. На другом устройстве той же сети откройте
`http://<LAN-IP-хоста>:4173`. Разрешите входящий TCP4173 в firewall своей системы.
Производственная сборка также запускается без Node:

```bash
python3 -m http.server 4173 --bind 0.0.0.0 --directory dist
```

Для разработки:

```bash
npm run dev -- --host 0.0.0.0
```

Для воспроизводимых браузерных тестов:

```bash
npx playwright install --with-deps chromium
npm run test:browser
```

Если скачивание Playwright browser недоступно, можно явно указать совместимый Chromium
через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/absolute/path/to/chromium npm run test:browser`.
Это только поверхность проверки; поставляемая страница не зависит от этого бинарника.
CI использует обычный Playwright install. Hosted-проверка не подтверждает реальное второе LAN
устройство: этот шаг оператор выполняет отдельно. Native project hook activation также NOT RUN.

Выберите S/M. Оба пресета явно экспериментальные, полный fitted SKU не подтверждён.
Параметры показывают canonical/derived/experimental origin с sourceRef; JSON содержит каждый
origin. α=5.65e-7 kg/(N s), σ=5.670374419e-8; малые SI числа не округляются до нуля.
S аккумулятор хранит3.6825GJ. Discharge efficiency0.9 применён ровно один раз.
Коэффициент добычи1 SCU/100MJ beam — именованный lab experiment, не U2 throughput.

«Запуск» создаёт immutable копию текущих параметров; изменение формы готовит следующий
опыт. «Пауза», «Продолжить», «Шаг», «Отмена» подтверждаются коррелированным Worker ACK.
Ускорение меняет размер batch, physics dt сохраняется. «Сброс» и валидный импорт создают
новый runId, старые сообщения игнорируются. Невалидный JSON оставляет последнюю конфигурацию.

Откройте модули для редактирования. Дополнительная палитра создаёт явно экспериментальные
варианты. H₂ cooler добавляет физический power tank с текущей S/M capacity curve; cargo H₂
не подключается. Применение палитры к M не утверждает M finished module. Для полного
изменения фаз, hysteresis, баков, initial stocks, источников и закона среды используйте
«Все параметры / фазы JSON». Все числа SI, units=SI; неподдерживаемые версии отвергаются.

Для A/B завершите или приостановите опыт A, нажмите «Зафиксировать A», измените настройки,
запустите B. Одинаковая задача использует targetWork; собственный рейс — заполнение трюма,
возврат и явная разгрузка. Незавершённые рейсы показываются как незавершённые. Несовпадающие
scenario/environment/duration видны в сравнении. Модели и параметры не скрываются.

JSON опыта сохраняет run spec/provenance, CSV — retained mean/min/max/count trace и события
с SI timestamps. JSON результата содержит сохранённые агрегаты и метрики. После отмены
доступен снимок. CSV не является полным raw tick архивом:1s buckets с детерминированным
слиянием при лимите50 000 /128MiB. Метрики учитывают все ticks; события сохраняют первые128
и последние19872, dropped count виден в UI и экспорте. Экран отображает текущую ограниченную
выборку событий и recent plot window; полный retained результат доступен в экспорте.

12 часов не предел: допускается любая положительная конечная duration. Повторяемый рейс
сохраняет запасы и тепло; разгрузка не refuel, отдых не сброс. Только явно указанная service
фаза может заправить или зарядить корабль. Движители на полной тяге — отдельный stress.

Откат: revert feature commits; исходные U2 данные не перезаписываются. Operator merge и
полное bootstrap acceptance остаются отдельными gates.

Численный long replay отделён от быстрых regression tests: `npm run test:long` выполняет
фактический S12h/dt0.01 с ограниченным хранением. `npm test` содержит64channel long-retention,
схему, модель, сценарии, ACK и I/O; browser suite отдельно измеряет Worker controls после40000 buckets.
