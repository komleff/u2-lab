`https://komleff.github.io/u2-lab/` должен открывать текущую модель корабля 0.1 и свежий

## HOW — одна ограниченная поставка

1. Developer пишет адресный RED на `page.goto('/')`: сразу рабочий /4, fresh0.3.3,
   нет необходимости нажимать entry button; URL не переписывается query-параметрами.
2. В `main.ts` стандартный вход выбирает /4 через существующий монтаж полной оболочки.
   Старый `mode=legacy` остаётся архивным reader. Для старых fitting tests/явной совместимости
   допустим скрытый `shipModel=legacy`, он не предлагается в нормальном UI. Не создавать
   второй reduced app и не менять shared численную модель. Старый experimental URL — alias.
3. В обычной /4 шапке убрать «Старый редактор» как рекомендуемый переход; сохранить
   существующий безопасный import старого документа с подтверждением/сохранением A/B.
   Никакого удаления readers, автоматической миграции или пересчёта старых JSON.
4. В shared shell имя GD LAB без смешанного номера. Footer «О Лабе»: версия Лабы2.6,
   интерфейс4.8 отдельно, фактическая модель/каталог. В нормальном входе не называть
   рабочую модель экспериментальным opt-in. Происхождение чисел/ограничения данных не
   превращать в блокирующие предупреждения; честные поля старых документов сохранить.
5. Обновить existing browser cases старого редактора на явный compatibility entry,
   существующие /4 acceptance chains запускать с чистого URL. Сохранить исторический
   experimental-link case. Обновить3 stale presentation assertions, не ослаблять проверки
   настоящего Worker, таймауты или конфигурацию. Обновить руководство и docs/INDEX.
6. Один полный `.agents/project/verify.sh` на frozen candidate под существующим Node24,
   затем independent QA по AC и один scoped Code Review. Устранить только blockers;
   один обычный finalize. Merge main выполняет оператор, агент его не делает.
7. По прямому поручению оператора опубликовать проверенную тестовую поставку v2.6 в
   existing gh-pages и GitHub Release v2.6.0. До operator merge source metadata обязана
   честно называть frozen feature SHA/ветку, а не main. Публикация тестового инструмента
   не объявляется merge. Тег ставится на exact проверенный source SHA.
   Сохранить архивы и старые hashed assets; build/release.json указывает Лаба2.6,
   интерфейс4.8, каталог0.3.3, source/runtime SHA. Проверить по HTTP хеши и реальный
   публичный H3600 по чистому URL; скачать release assets и сверить SHA256.

## Review Contract и границы

Review: routing startup, shared version presentation, сохранность старых import paths,
неослабленные entry-specific tests, docs/версионные metadata и publication binding.
Named risks: скрыто остался старый default; /4 урезан до нового экрана; сломан old import;
ложная версия каталога; stale assets/index; feature build ошибочно назван main.
OUT: новые законы энергии/тепла, перебалансировка, обнаружение, игровой runtime U2,
Unity/server parity, pipeline governance и переписывание приложения.
Budget PRODUCT5: PlanReview,QA,CodeReview,reserve affectedQA/scopedReview.
Rollback: восстановить прежний Pages index/release metadata при конкретном дефекте,
сохранив immutable assets и пользовательские файлы. Возврат старого default не является
запланированным поведением новой поставки.
