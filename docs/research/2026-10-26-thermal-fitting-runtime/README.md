# Измерения каталога 0.3.4

18 опытов выполнены реальным production runner без изменения каталога в памяти.
Принятые параметры не подгонялись под время перегрева. Это измерения Developer,
не независимая QA, не server parity и не production acceptance.

Исходный коммит: 7082ec74fca56eea67fcacacbf5268cfe2104ecd, Node 24.22.0,
каталог ship-fitting-0.3.4, seed 424242. Каждый вход содержит полную оснастку,
материалы, численные условия и initial state. Manifest связывает фактические
runtime-файлы с Git blobs этого коммита. Поздний evidence commit может иметь
другой SHA при неизменных runtime blobs.

Критических остановок в этих четырёх часовых опытах нет. Дополнительный Спутник
на 4500 с впервые ограничивается на 3843 с (64:03), в начале пятого рейса;
доставлено 120 SCU. По времени это близко к часу, по номеру рейса отличается
от ориентира «четвёртый». Предложение GD/PO: принять измеренный ориентир
64 минуты/пятый рейс для этого состава либо отдельно выбрать другой рабочий
маршрут/загрузку для сравнения. 40%, температуры и ТТХ ради кривой не менялись.

firstWorkLimit — первый endpoint физического tick, где реально работающий
двигатель/лазер оказался за рабочей температурной границей (разрешение 1 с).
firstCritical — первая защёлка thermalStopped установленного изделия.
Полные события сохраняют собственные физические timestamps. Работа, запасы,
mined/delivered/trips и причины ограничения берутся из runner. Расход топлива
считается как initial + stationReceived − final, а не initial − final.

## Холод: исходная температура корабля и фон разделены

Во всех холодных опытах фон 3 K; генератор выключен, аккумулятор остаётся
источником, собственные нагрузки корпуса работают. Пара 210 K отличается
только enabled нагревателя: само изделие установлено в обоих fit, масса/C
совпадают. Начальные 210 K уже ниже рабочей полосы — это опыт восстановления,
а не обычный старт 300 K.

| Опыт за 3600 с | T конца, K | Критическая остановка |
|---|---:|---|
| Дрейф из 300 K | 263.193088 | нет |
| Из 210 K, нагреватель OFF | 198.494938 | 3299 с |
| Из 210 K, нагреватель ON | 214.988758 | нет |
| Из 210 K, сняты два passive radiator | 227.476292 | нет |
| Из 225 K, нагреватель OFF | 227.558872 | нет |
| Из 225 K, нагреватель ON | 227.558872 | нет |

При 210 K нагреватель потратил 129,858 МДж и предотвратил критический холод
за этот час, но итог 214,989 K всё ещё ниже номинальной рабочей полосы.
Это не обещание полного восстановления при любой оснастке/питании.
Отрицательный контроль 225 K: в обоих случаях 227,558872 K, нагреватель
потребил 0 Дж — собственного тепла достаточно. Снятие пассивных радиаторов
меняет только явно названные изделия; их действительные mass/C также уходят
из состава, это отражено в spec. Выключение пассивного радиатора не закрывает
его поверхность и не выдаётся за снятие.

## Горячая среда и специализированное охлаждение

Мир D, стационарная добычная нагрузка 1800 с, старт 300 K. Контрольный состав —
обычный пассивный; специализированный добавляет существующий pump-radiator-S
в подходящий M-slot, H2-cooler-M и бак H2-M. Нового M-SKU насосного радиатора нет.
Добавленные материалы и источники включены в обе ведомости массы/теплоёмкости.

## Фактическая работа генераторов

Отдельные простои 3600 с начинаются с полной батареей; начальное бесплатное
энергосодержание существенно для конечного окна измерения.

| Борт | Измеренный ΔR генератора за час | Линейная проекция времени R1→0 |
|---|---:|---:|
| Спутник | 0.06806854 | 14.691 ч |
| Пони | 0.04215625 | 23.721 ч |
| Мир | 0.00000000 | не определена: генератор не включался |

Это **оценки по измеренному часу**, не фактически пройденные 15/20/60 часов.
Мир за первый час с полной батареей ещё не достигает порога источника 0,90,
поэтому измеренный износ 0 и конечная проекция отсутствует. Около 60 часов при
стационарной средней загрузке остаётся аналитическим ориентиром данных,
не результатом этого опыта. Коэффициенты двигателей не ускорялись новым
генераторным коэффициентом; фактические ΔR всех engine/generator есть в JSON.

## Погрешность, сохранение и повторение

Максимальный модуль остатка за шаг в нормальных рейсах 6,75e-6 Дж
(существующая граница mission-kernel 1e-4 Дж); в насосном горячем опыте 0,011284 Дж
(существующая TI-граница 0,1 Дж). Это численная согласованность, не точность
материальных/балансовых приближений. Границы взяты из действующих тестов,
а не ослаблены для новых кривых.

Независимый midpoint reference проверяет ангар за 10/3600 с, знак обмена,
равновесие 300 K и whole/split; реальные checkpoint и уже открытые/закрытые
панели проверяются адресными тестами. Legacy 55 measured rows и CP-vectors
остались побайтно прежними. Исторические 6 изменившихся source paths
проверены отдельно по Git blobs f0732d3, старым experiment pins и прежнему manifest.

Повторить из корня репозитория, Node24.22.0:

    node --no-warnings --experimental-loader ./docs/research/2026-10-26-diesel-balance/loader.mjs ./docs/research/2026-10-26-thermal-fitting-runtime/run.ts /tmp/thermal-repeat 7082ec74fca56eea67fcacacbf5268cfe2104ecd

receipts.json — индекс, метрики и state; отдельные JSON — полный spec/state/events/trace.
results.csv — сравнение; manifest.json — source fingerprints и SHA256 payload.
Повторная сборка обязана дать те же payload hashes. Неизменность source проверяется
самим скриптом перед запуском. Старые каталоги / 35 исследовательских опытов сохранены.

Независимые QA/scoped review, реальное устройство/LAN, production U2 и
публикация Pages проходят отдельно. U2 restart-schema blocker 230/480 K сохраняется.
