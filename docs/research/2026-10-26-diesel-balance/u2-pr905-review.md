# Сверка с U2 #905

В U2 [PR #905](https://github.com/komleff/u2/pull/905) подготовлена ревизия
`q1-candidate.4`. Рядом с этим документом лежат **точные копии** общих параметров
и трёх полученных F2-профилей. Первичный генератор и подробная сверка находятся
в U2 `docs/data/f2-ship-profiles/`; SHA-256 копий фиксирует
[sync-manifest.json](sync-manifest.json).

Это единый проверяемый набор данных, не активация нового каталога Лабы. Исторический
0.3.3 сохраняется для буквального открытия опытов. Новый набор должен подключаться
явно при интеграции; старые сохранённые результаты не пересчитываются.

| Решение | Состояние общего набора |
|---|---|
| D3 | Фиксированная пассивная поверхность включена один раз: Спутник/Пони 40 м² × 0,9; Мир 400 м² × 0,9, без добавления второй массы |
| D5 | Пони Industrial, производитель UNKNOWN |
| D7 | Обычные критические 200/550 K, рабочие 220–500 K, возврат 230/480 K; особые пределы баков сохранены |
| Двигатель | 40% собственных потерь в корабль; учитываются КПД двигателя и передачи |
| Радиатор | Разведены A/ε/K: S 490 × 0,9 = 441 м², M 1960 × 0,9 = 1764 м²; ε повторно не применяется |
| Монтаж | Пони D — D/E; Волна H — H/E. Смешивание внутри допусков разрешено; источник каждому потребителю обязателен для сохранения и запуска |
| Прогрев | У четырёх корпусов разрешены названные оператором сменные изделия. Встроенные RAM и оболочка Stealth не превращаются в разрешённые сменные модули |

Фактическая проверка `GovernorSchemaV03.cs` в main U2 подтверждает блокер: код
требует restartCold ≤ workLow и restartHot ≥ workHigh. Новый профиль намеренно
не зажимает значения под эту ошибочную проверку. До её исправления
`runtimeAuthorization=false`, `qualificationStatus=BLOCKED_RESTART_SCHEMA`.
Схема, загрузчик/manifest потребляющей линии и адресная квалификация должны быть
обновлены до активации; наличие JSON не является разрешением включить runtime.

Проверены массы и теплоёмкости, площади, полезная энергия аккумуляторов, границы
мощности генераторов, силы/расход/тепло двигателей, класс Пони и состав модулей.
Новые значения не подменяют открытые решения. Особо заметен D1:

| Сухая масса | Спутник | Мир | Пони |
|---|---:|---:|---:|
| Прежний лётный бюджет F1, т | 50,00 | 200,00 | 46,70 |
| Сумма физических изделий F2, т | 52,84 | 231,63 | 50,23 |

Лётные массы пока сохранены по прежнему паспорту F1. Рекомендация для физической
унификации — масса установленного состава плюс отдельно топливо/груз; это
снижает разгон при прежней тяге примерно на 5,4% / 13,7% / 7,0%. D1 не был
явно выбран оператором, поэтому эти новые лётные массы не объявлены принятыми.
Добычные пресеты Лабы содержат другой набор лазеров и трюмов: их суммарные
массы/C не обязаны равняться курьерскому составу F2.

Базовые 35 тепловых опытов измеряли прежний сервис и параметры; они сохраняются
как историческое evidence. Новые обычные температуры, 40%, фиксированная поверхность
и физические единицы требуют адресной повторной квалификации в потребляющем ядре.
Проверка этой поставки — воспроизводимость генератора, физические равенства
и точное совпадение данных между репозиториями, без заявления runtime PASS.

Термины: **A** — физическая площадь; **ε** — излучательная способность;
**K=A·ε** — эффективная площадь; **runtime** — исполняемый код; **manifest** —
список файлов с контрольными суммами.
