# Исследование ГД: стелс-класс Лабы, 2026-10-13

Опыты на движке Лабы v3 (каталог 0.3.1 и кандидаты класса), из которых получены числа документа
[«Класс „Стелс“»](../../product/stealth-class-v0.1.md). Это аналитическое evidence ГД, не runtime QA.

## Запуск

Из корня репозитория:

```bash
npx vitest run --config docs/research/2026-10-13-stealth-class/probes/vitest.probe.config.mjs <фильтр>
```

Сводки пишутся в `results/`, сырые ряды прогонов — во временный каталог системы
(`u2-lab-stealth-class`). Повторный запуск `final` воспроизводит `results/final.json` побайтно
(проверено на ветке `docs/stealth-class-v0.1`).

## Скрипты (`probes/`)

| Файл | Что делает |
|---|---|
| `harness.ts` | Прогон сборки на движке v3, съём температуры, буфера, заряда, топлива, сигнатур и дальностей |
| `helpers.ts` | Правки корпуса: встроенный задненаправленный радиатор, пассивная площадь |
| `stealthclass.ts` | Корпуса класса S/M/L, тихий водородный двигатель, модули L, гиродины, сенсор и экран M/L |
| `national.ts` | Именные модели и национальные оси: КПД, раскладка тяги, масса |
| `session.ts` | Замеры в масштабе сессии: окно в покое, импульсы до скорости FA, дальности спереди и сзади |
| `baseline.exp.ts` | Прежний `stealth-reference` против Спутника: покой, маскировка, манёвр |
| `heater.exp.ts` | Нужна ли встроенная электропечь: холодные поля 50 K, h = 5/15/30 |
| `buffer.exp.ts` | Подбор буфера под окно сессии |
| `uniform.exp.ts` | Девять моделей на одинаковых сборках — изоляция национальных различий |
| `hotel.exp.ts` | Национальный КПД собственных систем |
| `final.exp.ts` | Итоговые рекомендуемые сборки девяти именных кораблей |
| `area-gates.exp.ts` | Пассивная площадь S 120/170/230 м² и запас до температурных порогов за час игры |

## Результаты (`results/`)

- `baseline.txt` — прежний стелс: в покое нагрев 300 → 442 K за 6 ч без равновесия; на непрерывной
  полной тяге в маскировке EM 20,5 / 41 км (S / M-сенсор), аккумулятор пуст за 8 мин.
- `heater.txt` — встроенная печь нужна только в маскировке в ледяном ядре (h = 30): без неё 238 K за
  3 ч; в остальных пяти случаях не включалась.
- `buffer.txt` — буфер S 0,4 ГДж: покой 32 мин, манёвр 13 мин (3 цикла).
- `uniform.json`, `hotel.json`, `final.json` — сводки девяти моделей.
- `area-gates.txt` — при 120 м² IR и EM в маскировке равны (2,0 / 2,0 км), при 230 м² IR забивает EM
  (2,8 км); за час игры корабль не выше 345 K; в ледяном ядре без нагревателя 274 K при 120 м² и
  235 K при 230 м² через час.

## Найденные ошибки при постановке опытов (для повторяющих)

- События смены фаз вытесняют событие «буфер полон» из сохранённого списка — момент заполнения
  определять по уровню буфера, а не по событиям.
- Сценарий «10 % тяги часами» нереалистичен: игрок даёт полную тягу импульсами.
- Сравнивать марки — только на одинаковых сборках.
- Итоговая дальность — наибольшая из IR и EM; снижение одного канала ниже другого её не меняет.

## Ограничения

Сырые ряды прогонов не сохранены в репозитории (десятки мегабайт); радар, EM-чистота корпуса и
геометрия моделей — расчёт вне движка; восстановление после маскировки не проверяется из-за ошибки
разрядки буфера.
