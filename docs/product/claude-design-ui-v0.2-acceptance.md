# Поручение и главенство источников

Оператор поручил внедрить интерфейсы Ship Fitting и Power & Heat Lab из Claude Design,
PR #5, commit abbd2943d51bb2a063b056f38033aca5f03b064f. Затем явно отложил новые
исправления и функции лаборатории: полный шахтёрский рейс, добычу до заполнения трюма,
маршрут Аврора ↔ центр Северного и заправку. Эта работа сохранена в Beads ulab-dwi;
сейчас выполняется только интерфейс, ulab-3lg.

WHAT интерфейса — документ UX v2.1, Main/Lab и их мобильные/пограничные артборды,
снимок токенов. Численные правила — существующий GDD, решение о первой поставке и
SF01–20. Макеты не являются исполняемым приложением. Их числа, производители и результаты
— DEMO; вместо них интерфейс показывает каталог и текущие результаты Worker.

Это структурирование уже принятой раскладки, не новый проект физики. Форматы
u2-ship-fit/1, u2-lab/1/2, модель ship-fitting-ledger-0.2 и текущий сценарий сохраняются.
Фиксированная рабочая фаза остаётся лабораторным условием; интерфейс не называет её
реальным временем до полного трюма и не обещает рассчитанный рейс.

# Решения для переноса

1. Самостоятельные представления «Оснастка», «Power & Heat», «Сравнение» используют одно
   состояние. Переход не запускает новый Worker и не сбрасывает тест.
2. Встроенное изделие находится внутри своей категории, с замком и отдельным счётчиком.
   Оно не занимает сменный слот; параметры доступны, снять/заменить нельзя.
3. Полоса F1 и основное действие доступны при прокрутке. Круг — обзор тех же слотов,
   с fallback по UX §11.5; телефон использует плоский паспорт и сворачиваемые группы.
4. Варианты A/B/C и добавленные варианты — независимые сборки в памяти текущей страницы.
   Сохранение JSON сохраняет выбранную сборку в существующем формате. Снимок теста A
   для сравнения лаборатории — отдельная неизменяемая сущность, его подпись это различает.
5. Применённые замены сохраняются у варианта; переключение сбрасывает только неприменённый
   выбор в диалоге. Измерения принадлежат своему варианту и ревизии. Изменённая сборка
   помечает свой прежний результат устаревшим, без переноса чужих измерений.
6. Один действующий тест на всю страницу. При переключении на другой вариант текущий
   тест сохраняется с указанием владельца; второй запуск недоступен до его завершения,
   отмены или сброса. Правки сборки относятся к следующему запуску.
7. Пакетная замена касается только сменных Payload slots. Предпросмотр и применение —
   одна проверенная транзакция всей сборки; отказ не изменяет ничего, успех даёт одну
   новую ревизию. Встроенный лазер/трюм не участвует в пакетном выборе.
8. Условия активного/приостановленного теста заблокированы. Карточки оснастки остаются
   доступны для следующей ревизии. Нулевые запасы предупреждают, но не запрещают тест.
9. В UI используется слово «тест»; поля protocol/schema и имена файлов API не переименуются.

# Два вопроса пакета Claude

Демо-таблица не устанавливает канонический результат или первое ограничение: оба
вычисляются текущим движком. «Тепло» у одного лазера само по себе возможно и не требует
подмены данных. K_use включает весь цикл/горизонт, включая перелёт/обслуживание согласно
GDD §7; он не пересчитывается только по времени включения лазеров.

«Титан» — принятое M-имя в frozen каталоге U2. Визуальный пример допустим только с
явной подписью «лабораторный профиль Industrial M · экспериментальный» и текущими числами
Industrial M. Он не становится утверждённой карточкой ТТХ Титана. Иные корпуса используют
свои фактические labels. Изображение — иллюстрация, не источник габаритов/слотов.
Назначения производителей модулей из DEMO не переносятся: при отсутствии поля в
каталоге пишется «производитель не указан». Каталог не расширяется ради макета.

# Честные измерения

Номинал и измерение разделены. До теста — заглушки, при расчёте — предварительные
показатели; после правки — пометка устаревшей сборки. Неполный цикл и отмена показывают
наблюдаемый интервал. Ноль добычи даёт неопределённый расход на SCU с абсолютным расходом.
Канал или показатель, которого нет в snapshot, не заменяется выдуманным числом.
Полоска экземпляра подписывает используемый измеренный интервал; последнее измерение
не называется средним за весь тест. Сравнение указывает различающиеся условия.

Область проверки — работоспособность перенесённого интерфейса, достоверность привязки
данных и доступность функций на ПК/планшете. Постоянный локальный стенд остаётся включён.
Bootstrap, native hooks, operator merge и новый public Pages deploy не входят в эту приёмку.

# Глоссарий

- Вариант — отдельная сохранённая в памяти сборка.
- Ревизия — номер применённого изменения сборки.
- Снимок A — неизменяемый результат для сравнения тестов.
- DEMO — пример для раскладки, не результат симуляции.
- F1/F2/F3 — итог, оснастка и детали по запросу.
