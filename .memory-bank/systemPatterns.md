# System Patterns

Один скалярный электрический баланс через общий аккумулятор; одна общая T_ship с
конечной material-derived теплоёмкостью. Частные буферы — внутри определённых устройств.
Чистое расчётное ядро отдельно от UI; сценарий задаёт нагрузку и изменения среды.
Версии модели, конфигурации, сценария и provenance входят в сохранённый опыт.
Базовая модель следует current U2; экспериментальные варианты маркируются отдельно.
Тепловой фон, прямой нагрев и энергетические поступления не учитываются дважды.
