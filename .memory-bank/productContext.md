# Product Context

Основной цикл: выбрать корпус/модули, среду и сценарий → запустить → увидеть ограничения
по графикам и событиям → изменить параметры → сравнить A/B.
Сессии: 5–10 минут до 8–12 часов; длительность опыта произвольна, длинные опыты —
повторяющиеся рабочие циклы с ресурсами и восстановлением.
Физика — инструмент относительно честной балансировки. Формулы можно менять ради
геймплея, но изменения должны быть явными и воспроизводимыми.
Нет проводов/труб. Обнаружение и настройка сенсоров/радаров отложены оператором.
